# Sprint 036-CL transcript: the CLI files a PNG and a PDF beside a note

Run 2026-11-04 against the worktree dev server (`http://localhost:5214`) as a fresh user
`qa-036-transcript-*@chronolog.test` with an API token, using `node cli/chronolog.mjs` (shown as
`chronolog`). `<tmp>` is a temporary directory: `<tmp>/files/` holds the test files (a 16x16 PNG, a
one-page PDF, a `.txt`, a PDF renamed `invoice.png`, and a PDF padded to 10 MB + 1 byte) and the CLI
ran in `<tmp>/downloads/`, so `attachment get` without `--out` saved there. Every step ends with
the CLI's exit code. The test files were generated by `src/e2e/attachment-fixtures.ts`.

The automated versions are `src/e2e/attachments-cli.e2e.test.ts` (API e2e) and
`e2e-playwright/cli-attachments.spec.ts` (Playwright): a PDF attached by the CLI shows in the editor
as a link with a document icon and in the attachment list with its size, and both open it in a new
tab. Screenshots: `01-editor-pdf-link-and-attachment-list.png` (editor and list) and
`02-attachment-list-row.png` (the list row).

Note ids share one sequence per client short code and day across all users of the dev database,
hence `.211`.
