## Limits of interpretation

The latest request does not approve a particular production motif set, assignment/collision policy, every incidental detail in the raster, or a time-entry background wash. Those remain deferred. The two percentage changes are sequential relative adjustments: 0.85 × 1.10 = 0.935 of the original reference height, not a net five-percent reduction. Since the reference images have no established CSS scale, this arithmetic does not supply a production pixel size.
